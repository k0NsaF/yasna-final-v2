# Ясна — система записи и учёта занятий мастерской

## О проекте

«Ясна» — информационная система для небольшой детской мастерской.

Система предназначена для:
- ведения семей и данных детей;
- создания расписания занятий;
- записи и отмены записей на занятия;
- учёта посещаемости;
- ведения абонементов и остатка занятий;
- учёта платежей;
- прикрепления чеков и квитанций;
- уведомлений для родителей;
- экспорта отчётов в CSV.

## Установка

Клонируйте или скачайте проект.

Перейдите в корневую папку:

```powershell
cd yasna
```

Создайте виртуальное окружение:

```powershell
python -m venv .venv
```

Активируйте его в Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установите зависимости:

```powershell
pip install -r requirements.txt
```

## Запуск сервера

Из корневой папки проекта выполните:

```powershell
python -m uvicorn backend.app.main:app --reload
```

После запуска:

- API: http://127.0.0.1:8000
- Swagger: http://127.0.0.1:8000/docs
- Проверка состояния: http://127.0.0.1:8000/api/health

База SQLite создаётся при запуске приложения.

## Демо-данные

Для создания демонстрационных данных выполните:

```powershell
python -m demo_data.seed
```

Скрипт создаёт демонстрационную семью, двух детей, занятия, абонемент, платёж, посещение и уведомление.

Повторный запуск не создаёт вторую демо-семью с тем же демонстрационным телефоном.

## Авторизация

В системе предусмотрены два типа доступа:

1. Мастер — авторизуется через API входа мастера.
2. Родитель — использует персональную ссылку семьи.

Персональная ссылка семьи должна храниться конфиденциально. При утрате или компрометации мастер может отозвать её и создать новую.

Не публикуйте токены доступа и не отправляйте их посторонним.

## Основные возможности API

| Раздел | Назначение |
|---|---|
| master | Управление мастерской и семьями |
| family | Личный кабинет родителя |
| lessons | Расписание занятий |
| bookings | Запись и отмена записи |
| attendance | Учёт посещаемости |
| subscriptions | Абонементы |
| payments | Платежи |
| receipts | Чеки и квитанции |
| notifications | Уведомления |
| reports | CSV-отчёты |

Полный список запросов доступен в Swagger.

## Платежи и чеки

В демонстрационной версии используется тестовый сценарий учёта платежей. Реальное списание денежных средств не выполняется.

Чеки и квитанции прикрепляются мастером вручную после оформления в соответствующем сервисе.

## Резервное копирование

Для создания резервной копии базы данных выполните:

```powershell
python backup_database.py
```

Файлы резервных копий сохраняются в папке `backups`.

Рекомендуется создавать копию перед обновлением проекта и перед демонстрацией.

## Безопасность

- Не публикуйте файл `.env`.
- Не публикуйте токены авторизации.
- Не загружайте рабочую базу данных с персональными данными в открытый доступ.
- Для реального развёртывания необходимо настроить надёжные секреты, HTTPS, постоянное хранилище и полноценную систему управления сессиями.

## Статус проекта

Проект подготовлен для локального демонстрационного запуска.

Перед эксплуатацией в реальной мастерской требуется дополнительная проверка безопасности, резервного копирования, обработки ошибок и развёртывания.
